# Sovereign release model

A controlled artifact follows this chain:

```text
Native evidence
  → repository adapter obligations
  → structured qualifications
  → monotone publication algebra
  → derived publication status
  → classification and purpose declaration
  → payload- and policy-bound TrustDecision
  → canonical-byte emission
  → signed integrity manifest
```

Controlled releases include owner-held data, derivatives of owner-held data, and non-unrestricted disclosure classes. These require a managed signing key by default. Policy-version changes require an explicit migration record and fresh evaluation.
